# A股股票财报一键下载与智能分析平台 (A-Share Report Hub)

一站式A股上市公司财报极速检索、官方定期报告原件(PDF)单篇与历年打包下载、财务三表(Excel/CSV)结构化导出及财报关键指标与杜邦分析可视化看板。

## User Review & Critical Decisions

> [!IMPORTANT] 
> 基于 Phase 1 用户确认的选型与业务逻辑汇总：

- **财报内容范围 (已确认)**：同时支持上市公司官方披露的**定期报告原件全文 (PDF)**（年度报告、半年度报告、一季度报告、三季度报告）以及**资产负债表、利润表、现金流量表结构化数据导出 (Excel/CSV)**。
- **打包与下载模式 (已确认)**：支持**单篇快速直链下载**与**单只股票指定年度/全周期定期报告一键合并打包为 ZIP** 下载；三表数据支持合并导出为带有格式化工作表的多Tab Excel 文件。
- **可视化与数据速览 (已确认)**：内置财报在线预览抽屉、核心财务指标（营业收入、归母净利润、毛利率、净利率、资产负债率等）多期趋势折线图，以及**经典杜邦分析体系 (ROE = 销售净利率 × 资产周转率 × 权益乘数)** 拆解看板。
- **公开数据源协同机制 (设计决议)**：
  - 官方PDF公告：对接巨潮资讯网 (cninfo) 官方定期报告数据源，备用采用深交所/上交所/东方财富公告接口，确保真实官方盖章/披露文本。
  - 财务三表结构化数据：采用新浪财报开放接口与东方财富核心指标，经后端自动化对齐报告期与会计科目。
  - 实时行情与估值辅助：接入腾讯行情开放 API，同步展示现价、PE-TTM、PB、总市值等基础参考数据。

## 1. Overview & Core Concept

- **What It Does**: 用户只需输入A股股票代码（如 `600519`、`000001`、`300750`、`688981`）或拼音首字母/名称（如“贵州茅台”、“平安银行”），系统即可瞬间呈现该上市公司全部历史定期报告列表与核心财报数据。用户可勾选目标年份（如近3年、近5年或全选），一键打包下载全部官方PDF报告，或一键导出清洗整齐的财务三表Excel文件；无需下载时亦可在页面即时查看关键财务指标走势与杜邦分析。
- **Target Audience / Persona**: 证券研究员、个人价值投资者、财务分析师、会计与商科师生、量化策略研究员，告别繁琐在交易所多层跳转和人工单篇另存为的痛点。
- **Key Value**: “秒级检索、原件保真、三表立转、打包即走、可视化秒懂”。

## 2. User Experience & Visual Design

### Key User Flows

1. **首页检索与热门直达**：
   - 顶部具备全局股票智能搜索框（支持实时联想与模糊匹配，内置茅台、宁德时代、比亚迪、招商银行等热门白马股一键气泡填充）。
   - 检索后自动加载股票基本面标头（股票名称、代码、板块、当前股价、PE/PB、流通市值、所属行业）。
2. **财报检索与筛选**：
   - 报告类型切换：`全部` / `年度报告 (年报)` / `半年度报告 (半年报)` / `一季度报告` / `三季度报告`。
   - 时间跨度快捷筛选：`全部年份` / `近3年` / `近5年` / `近10年` / 自定义年份多选。
3. **一键下载体验**：
   - **单篇极速下载**：每条财报卡片/表格行提供“下载PDF”与“在线速览”。
   - **一键打包ZIP**：点击“打包下载所选 (N篇)”，后端即时生成标准结构化ZIP压缩包（内含按 `股票代码_股票名称_报告年份_报告类型.pdf` 规范命名的文件）。
   - **财务三表一键导出**：一键导出包含 `资产负债表`、`利润表`、`现金流量表`、`关键比率速览` 4个清晰Sheet的 `.xlsx` 格式文件，支持日期横轴对齐。
4. **财报要点可视化与杜邦看板**：
   - 切换到“财务指标趋势”Tab：展示近5年/近8期营业收入与净利润对比图、毛利率/净利率走势、资产负债率与现金流柱状图。
   - “杜邦分析模型”看板：树状分解 ROE 核心三要素（销售净利率、总资产周转率、权益乘数），直观定位驱动ROE变动的根源。
5. **PDF在线阅读抽屉**：
   - 点击预览无需跳转离开页面，在右侧沉浸式抽屉内直观查看官方披露文档关键章节及摘要。

### Visual Identity & Theme

- **Aesthetic Direction**: 严肃、专业、高效的金融级终端美学（Financial Analytics Utility），融合顶级研报终端与现代轻量级 SaaS 体验，杜绝浮夸紫色渐变与无意义装饰。
- **Color Palette & Mood**:
  - Canvas 背景：暖白底色（`#F8FAFC` / `bg-slate-50`），深色模式为沉浸暗灰墨色（`#0B0F17` / `bg-slate-950`）。
  - Structural Surface：卡片与表格背景（`#FFFFFF` / `#111827`），搭配精致细腻的发丝级边框（`border-slate-200 dark:border-slate-800`）。
  - Financial Accents：
    - 主交互色：金融深海蓝（`#1D4ED8` / `text-blue-700`），象征严谨稳健。
    - A股特色涨跌配色：涨红（`#DC2626` / `text-red-600`）、跌绿（`#16A34A` / `text-emerald-600`）标准财务指示。
    - 辅助指示：琥珀金（`#D97706`）用于审计意见强调及年报高优先级标识。
- **Typography & Hierarchy**:
  - 标题与品牌：`Plus Jakarta Sans` 搭配沉稳中文字体族（PingFang SC, Microsoft YaHei）。
  - 数据与时间戳：严格启用等宽数字（`font-mono tabular-nums`），确保财务表格所有金额与百分比数值严格上下垂直对齐。
- **Spatial Composition**:
  - 1440px 桌面空间标准布局，中央主体 1200px 紧凑规整，避免卡片套卡片。
  - 元数据展示严格遵循零胶囊设计原则（Zero-Pill Discipline），使用无框纯文字加中间点隔断（`·`）。

## 3. Key Product Decisions & Trade-Offs

- **决策 1：官方定期报告原件获取与后端下载代理**
  - *Chosen Approach*：在 Node.js Express 后端搭建聚合代理服务（`/api/reports` 与 `/api/download/pdf`、`/api/download/batch-zip`）。
  - *Why*：巨潮资讯网与交易所对直接客户端静态 fetch 有严格的防盗链（Referer）与跨域（CORS）控制，纯前端 fetch 无法下载二进制文件。后端代理可无缝注入合规 Referer/User-Agent 标头，并直接利用流式流传输（Stream Pipeline）快速打包 ZIP，无需客户端逐个等待下载。
- **决策 2：结构化三表 Excel 生成方案**
  - *Chosen Approach*：后端采用轻量级 `exceljs` 或 `xlsx` 库将新浪/东财三表接口的数据组织为标准的四表合一 Excel 工作簿，同时提供前端纯内存下载兜底。
  - *Why*：投资者拿到Excel可以直接开展DCF估值、比率计算或导入量化数据库，规避传统网页复制粘粘格式错位的问题。
- **决策 3：杜邦分析与图表呈现**
  - *Chosen Approach*：采用原生轻量 SVG/HTML5 Canvas 图表与交互式树状分解图，无需庞大重型分析软件即可在毫秒内完成指标连乘演算与各期对比。

### Data Model & Key Endpoints

1. **`StockMeta`**:
   - `code`: 6位纯数字股票代码 (如 `"600519"`)
   - `name`: 股票简称 (如 `"贵州茅台"`)
   - `market`: `"sh"` | `"sz"` | `"bj"`
   - `price`, `pe_ttm`, `pb`, `mcap_yi`, `industry`
2. **`ReportItem`**:
   - `id`: 公告唯一标识
   - `title`: 财报标题 (如 `"2025年年度报告"`)
   - `year`: 报告归属年份 (如 `2025`)
   - `category`: `"annual"` (年报) | `"semi"` (半年报) | `"q1"` (一季报) | `"q3"` (三季报)
   - `publishDate`: 官方披露日期 (YYYY-MM-DD)
   - `pdfUrl`: 官方 PDF 访问链接
   - `fileSize`: 文件大小预估
3. **`FinancialStatements`**:
   - `periods`: 历期报告期数组 (`["2025-12-31", "2024-12-31", ...]`)
   - `fzb`: 资产负债表行项 (总资产、货币资金、存货、应收账款、总负债、股东权益等)
   - `lrb`: 利润表行项 (营业收入、营业成本、销售费用、研发费用、净利润、归母净利润等)
   - `llb`: 现金流量表行项 (经营活动现金流净额、投资现金流净额、筹资现金流净额)
   - `dupont`: 杜邦三项指标分解历年序列 (ROE、净利率、周转率、权益乘数)

### Interactive State Transitions

- **初始态 (Empty/Landing)**：展示热门龙头标的与说明卡片，用户点击任一股票或输入回车即触发全局拉取。
- **加载态 (Loading)**：表格呈现平滑骨架占位，保留原有检索框架不抖动。
- **批量勾选态 (Selection Active)**：顶部浮现批量下载控制条，实时显示“已勾选 X 份财报，预估大小 Y MB”，支持“全选年报”、“近3年全选”快捷动作。
- **打包进度态 (Packaging Stream)**：点击批量下载后显示打包提示，后端流式推送并触发浏览器原生另存为。
